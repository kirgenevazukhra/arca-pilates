# ARCA — сайт студии пилатеса на реформерах

- `index.html` — весь сайт в одном файле (HTML + CSS + JS). Откройте в браузере.
- `DESIGN-SYSTEM.md` — разбор референсов и токены дизайн-системы.

## Куда ставить фото
В секции «Пространство» два блока `<figure class="photo">` содержат CSS-сцену-заглушку
(`<div class="scene">`). Замените её на `<img src="img/…jpg">` — эффект Ken Burns
при появлении применится автоматически.

## Анимации
- прелоадер с «дыханием» арки и появлением букв названия;
- гало арок в hero и в секциях (медленное свечение);
- параллакс арок за курсором;
- line-art-фигура на реформере: ноги в ремнях двигаются, каретка едет;
- секция «Движение»: три позы (ремни, мяч над головой, боковая планка) — переключаются
  при наведении и по таймеру;
- reveal-по-скроллу, бегущая строка, ховеры карточек и футера.
